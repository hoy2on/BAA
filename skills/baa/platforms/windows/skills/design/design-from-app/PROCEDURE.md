# Tauri reference design

Use the [BAA execution rules](../../../../../EXECUTION.md) already established for this task. Preserve the assigned Windows target, current stage, file ownership and acceptance; do not create a nested team.

Inspect the actual references, screen sizes, states and user task. Separate transferable hierarchy/spacing/interaction from platform-specific chrome, assets and fonts. Keep existing product structure/tokens unless a broader redesign was requested.

Compare corresponding content at matching viewport, zoom, state and data. Map the agreed design to existing frontend components and Tauri window behavior; do not infer native controls from a screenshot. Return inspectable alternatives when requested, and implement only the selected/authorized scope. Use layout-grid and actual Windows captures for the changed surfaces.
