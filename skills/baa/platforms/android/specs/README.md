# Android specs

Optional example build plans for native Android apps. Start with [Pocket Notes](pocket-notes.md).
Provide the spec or its full path when invoking BAA:

```text
/baa-android Build the app described in pocket-notes.md.
```

The common app-brief/user-stories procedures preserve the Brief and Stories in project docs;
Android scaffold/code/design/ship roles implement the plan. Don't regenerate an existing project.
Confirm the actual SDK, Gradle tasks, dev variant and selected phone/tablet scope.
This spec doesn't authorize installation over Release, data resets, commits, uploads or store submission.

This optional Android example does not impose its scope or a new starter on existing apps.
