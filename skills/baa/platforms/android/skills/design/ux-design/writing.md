# Android writing

Use the existing string resources and product vocabulary for labels, validation, progress and errors. A system Back action and an explicit Cancel button may have different draft behavior; document both.
Provide a visible touch route to essential actions. Give icon buttons meaningful descriptions and state, but avoid describing a decorative icon twice when the row already supplies the label. Verify plurals and the longest translations at large font scale.
An error should preserve input and name a recovery action. Do not show internal Gradle, Intent or repository names to users.
