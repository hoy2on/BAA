# Mobile writing

Keep product terms shared, but choose iPhone/iPad actions from their actual interaction. A button names the result (Save, Add note); a Back label names the destination. Do not expose scheme, actor, or database terms in product copy.
For each changed action, record its visible title, accessibility label, progress, recoverable error, and cancel/undo wording in the existing localization resources. Preserve draft text when validation or saving fails.
Review the longest supported translation and plural forms on the target device. A tooltip is not the only explanation for a touch action. If an icon already has visible text, avoid a second redundant spoken name.
